    Type Declaration

      • (
            ctx: { maxPages: number; page: BrowserPage; startUrl: string },
        ): Promise<string[]>

      • Crawls links on the starting host, visiting at most maxPages pages. Prints progress as pages scraped / pages to scrape (discovered so far, capped at maxPages): an in-place bar in a terminal, a line every 10 pages otherwise.

        Parameters

        • ctx: { maxPages: number; page: BrowserPage; startUrl: string }
          • maxPages: number

            Maximum number of pages to visit; 0 skips crawling.

          • page: BrowserPage

            Browser page used to visit links.

          • startUrl: string

            URL to begin crawling from.

        Returns Promise<string[]>

        Same-host links found on visited pages, including pages not visited due to the cap.

    crtHosts

    crtHosts: (opts: { rootDomain: string }) => Promise<Set<string>>

    Type Declaration

      • (opts: { rootDomain: string }): Promise<Set<string>>

      • Hostnames under rootDomain seen in Certificate Transparency logs (crt.sh). Makes up to 3 attempts (1 + 2 retries) with a growing delay; wildcard entries are dropped. Never throws: failures are logged and an empty Set is returned.

        Parameters

        • opts: { rootDomain: string }
          • rootDomain: string

            Registrable domain, e.g. "example.com".

        Returns Promise<Set<string>>

        Lowercased hostnames, including rootDomain itself if present.

      • Collects page URLs from the sitemaps listed in robots.txt (falls back to /sitemap.xml). Follows sitemap indexes and gzipped sitemaps, capped at 200 sitemap files. The page must already be on origin.

            Page-based fetch helper.

          • origin: string

            Site origin, e.g. "https://www.example.com".

        Returns Promise<string[]>

        Every <loc> URL found; may contain duplicates and other hosts.

    Type Declaration

      • (
            opts: { host: string; rootDomain: string; subdomains: boolean },
        ): Promise<string[]>

      • Historical URLs (HTML, status 200, deduplicated, max 50k) from the Wayback Machine CDX index. Never throws: failures are logged and an empty array is returned.

        Parameters

        • opts: { host: string; rootDomain: string; subdomains: boolean }
          • host: string

            Hostname to query, e.g. "www.example.com".

          • rootDomain: string

            Registrable domain, e.g. "example.com".

          • subdomains: boolean

            If true, query the whole root domain instead of host only.

        Returns Promise<string[]>

        Archived URLs, or [] if the service fails or answers with non-JSON.
